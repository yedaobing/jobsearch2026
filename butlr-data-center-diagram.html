Data Center Program Workflow

Butlr Senior Program Manager, Data Operations: one owner from signed deal to expansion
Gate: must pass to enter next phase ↺ Failed gate loops back
Deal commitment from Sales Long-term contract and updated playbook
Phase 1
Initiate
  • Kick off Butlr, partner, and customer teams
  • Set roles, timeline, comms cadence
  • Turn deal commitments into one plan
  • Baseline milestones, dependencies, owners
G1
Plan approved
RACI agreed; both sides accept baseline
Phase 2
Prepare
  • Configure, test, and QA POC units
  • Ship and clear customs with Shenzhen team
  • Secure site access and install windows
  • Design BMC, API, and alert integrations
G2
Ready to install
Units on site; window set; interfaces agreed
Phase 3
Pilot and validate
  • Install in live hall with no shutdown
  • Cover racks, busway, RPP, PDU, CDU, pipes
  • Run validation tests with engineering
  • Compare thermal twin to CFD; tune
G3
Validation passed
Devices reporting; alerts accurate; test report
Phase 4
Integrate and launch
  • Take integrations live; verify data flows
  • Run pre-launch readiness with Product
  • Confirm configs, docs, and support
  • Controlled go-live
G4
Customer accepts
Data live in customer tools; readiness signed
Phase 5
Operate and expand
  • Lead technical customer success
  • Monitor system health and adoption
  • Run check-ins; resolve issues fast
  • Bring expansion and upsell to Sales
G5
POC converted
Contract or expansion in pipeline
Every week, all phases Track the plan  ·  Raise risks early  ·  Push blockers to resolution  ·  Report status inside and outside Butlr  ·  Capture playbook lessons
