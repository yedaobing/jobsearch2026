--- layout: default title: "AI Infra On-Prem Build: Hardware TPM Workflow" --- {% capture workflow %} # AI Infrastructure On-Prem Build: Hardware TPM Deployment Workflow ## Purpose and scope This page maps the hardware deployment workflow for a **Senior TPM, AI infrastructure on-prem builds** (Redmond). The workflow starts when a data hall row is handed over by the facility team and ends when the energized row is handed to customer engineering. **Assumptions** 1. Before this workflow starts, the TPM coordinates with the facility team, the general contractor (GC) and other TPMs on construction and gray space fit-out. Facilities delivers white space power through the busway and white space cooling through the rack drop. 2. Hardware is delivered **row by row** up to rack energization. Each energized row is then handed to customer engineering for further testing and platform engineering. **Demarcation points** | Domain | Facility scope ends at | Hardware scope starts at | |---|---|---| | Power | Energized, commissioned overhead busway (A and B per row) | Tap-off install, rack feeds, rack PDUs | | Cooling | Commissioned secondary loop (TCS) at each rack drop's isolation valve or quick disconnect, flushed and filled, bypass jumper in place | Rack-to-drop connection, rack fill, air purge, leak check | | Network | Cable trays and pathways in place | Rack cabling, optics, management network turn-up | Confirm these demarcation points in the RACI at the start of the build. The usual constraints are crew capacity, facility handover dates, and how fast facilities can top up the coolant loop as racks fill. ### Milestones and major tasks | Milestone | Level | Major tasks | |---|---|---| | **M0. Build plan baselined** | Program, once | Confirm scope boundaries and demarcation with facilities and customer engineering. Build the integrated schedule: facility handover dates by row, rack deliveries, crew capacity. Set the row sequence. Stand up the tracker, RAID log and meeting cadence. Agree the handoff package and acceptance criteria. | | **M1. Row handover from facilities** | Row | Walk the row with the facility team, GC and commissioning agent (CxA). Confirm L5 integrated systems testing is complete for the row's power and cooling. Confirm the busway is energized, labeled and mapped to A/B. Confirm the secondary loop is flushed, filled, at design flow and temperature, with bypass jumpers in place. Confirm hall leak detection, cable trays, overhead clearance, floor loading and access control. | | **M2. Row materials staged** | Row, in parallel with M1 | Receive racks. Inspect crates and shock and tilt indicators. Capture serials into the asset system and match them to factory rack test (L11) results. Stage tap-offs, hoses and quick disconnects, optics, cables and spares. Quarantine and RMA damaged items. | | **M3. Racks set in place** | Rack | Move racks from staging to position per the floor layout. Level, anchor (seismic where required), ground and bond. Check clearance for doors, hoses and cable entry. Verify each rack ID matches its layout position. | | **M4a. Power connection** | Rack | Install tap-offs to each rack's spec. Land A and B feeds. Verify breaker ratings, phase rotation, voltage and labels. Confirm rack PDU monitoring in BMS/DCIM. | | **M4b. Liquid connection** | Rack | Remove the bypass jumper. Connect the rack manifold to the drop with dry-break quick disconnects (servers usually arrive pre-plumbed to the rack manifold). Fill, purge air, run a pressure hold and leak check. Verify in-rack leak sensors alarm to BMS. Facilities tops up the loop and rechecks water quality. | | **M4c. Network cabling** | Rack and row | Run and dress out-of-band (OOB) management, front-end, back-end GPU fabric (InfiniBand or RoCE) and storage cables to the cutsheet. Install optics. Test continuity and light levels, label both ends and record results. | | **M5. Staged rack energization** | Rack | Run the pre-energization checklist. Power on racks in a staggered order. Confirm power shelves and PSUs are healthy with no breaker trips. Confirm CDU flow and temperature hold under load. Confirm BMCs get DHCP leases on the OOB network and report to monitoring. Log all alarms and failed parts. | | **M6. Row handoff** | Row | Assemble the handoff package. Walk the row with customer engineering. Agree open items with owners and dates. What the TPM does | Milestone | TPM actions | |---|---| | M0 | Own the RACI and demarcation. Build the integrated schedule with partner EMs and TPMs (supply chain, network, compute). Define gate criteria. Set the cadence and escalation path. | | M1 | Schedule and lead the row walk-down. Drive the facility punch list to closure. Do not accept a row with blocking items. | | M2 | Track inbound shipments against row dates. Reconcile against the BOM. Drive expedites and RMAs for shortages and damage. Flag at-risk rows early. | | M3 | Confirm crew and rigging windows. Sequence racks so aisles are not blocked. Check placement against the layout. | | M4 | Run power, liquid and network connections in parallel. Share the coolant fill schedule with facilities so they can top up the loop. Route each failure to its owner with evidence. Keep the per-rack checklist current. | | M5 | Chair the go / no-go. Publish the energization order and stagger. Be on site. Log results. Decide hold or de-energize with the technical leads. | | M6 | Assemble the handoff package. Run the walk-through with customer engineering. Track open items to closure. Capture lessons for the next row. | ### Operating rhythm **Daily (on site)** - Stand-up with crews: rows in each stage, today's targets, safety notes. - Every blocker has one owner, one next action and a due date. - Share tomorrow's fill and energization plan with facility operations. **Weekly** - Report program health to leadership: rows by stage, gate pass rate, slips, top risks and mitigations. - Review dependencies with partner EMs and TPMs: supply, network, firmware, staffing. - Look ahead at facility handovers and deliveries for the coming weeks. - Fold lessons learned into the gate checklists. ### Minimum row record | Category | Fields | |---|---| | Identity | Hall, row ID, rack IDs, rack type, planned and actual dates per milestone | | Readiness | Facility handover status, commissioning report links, punch list items | | Materials | Rack serials, receiving status, BOM reconciliation, RMA list | | Connections | Per-rack power, liquid and network checklist status with test record links | | Energization | Go / no-go result, energization log, alarms, failed parts | | Handoff | Package status, open items, acceptance date | | Blockers | Description, owner, next action, due date, escalation level | ## 4.
